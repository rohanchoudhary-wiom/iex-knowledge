# Full-fleet ping-outage H3 map

Map the unsampled July ping population and strict twelve-missed-slot telemetry outages to H3 resolution 9 without exporting device identities or exact coordinates.

The completed run retained 84,789 July devices, mapped 81,772 (96.44%), and produced 3,167 privacy-safe H3 rows covering 89.94% of service-eligible mapped devices. It found 608,940 July-started telemetry outages across 74,732 devices. This is mapping evidence, not cross-device clustering, customer-service outage truth, or predictive performance.
